# hanji 사용법

한글(HWP·HWPX) 파일과 PDF, 이미지, 동영상을 열고 다른 형식으로 바꾸는 프로그램입니다.
PDF를 나누거나 합치는 것, 동영상에서 사진을 뽑는 것도 됩니다.
설치해서 쓰시는 분을 위한 안내입니다. 화면에 실제로 뜨는 문구와 눌러야 할 버튼을
그대로 적어두었으니, 순서대로 따라오시면 됩니다.

다른 변환 사이트와 다른 점이 하나 있습니다. 파일을 어디로도 보내지 않습니다.
그래서 나중에 지워달라고 요청할 것도 없습니다.

---

## 1. 설치

### 윈도우

1. [Releases](https://github.com/sylvanus4/hanji/releases)에서 `hanji_0.1.0_x64-setup.exe`를 내려받습니다.
   (`.msi` 파일도 같이 있는데, 회사에서 배포용으로 쓰는 형식이라 개인은 `.exe`를 받으시면 됩니다.)
2. 내려받은 파일을 실행하고 안내대로 눌러 설치합니다.
3. 시작 메뉴에서 hanji를 실행합니다.

설치 중에 "Windows에서 PC를 보호했습니다"라는 파란 창이 뜰 수 있습니다.
**추가 정보**를 누르면 아래에 **실행** 버튼이 나옵니다. 그 버튼을 누르세요.
프로그램에 유료 인증서를 붙이지 않아서 나오는 안내일 뿐, 파일에 문제가 있다는 뜻이 아닙니다.

### 맥

1. [Releases](https://github.com/sylvanus4/hanji/releases)에서 `hanji_0.1.0_universal.dmg`를 내려받습니다.
   인텔 맥이든 M칩 맥이든 이 파일 하나면 됩니다.
2. 파일을 열고 hanji 아이콘을 옆의 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 hanji를 **우클릭한 다음 열기**를 고르고, 다시 한번 **열기**를 누릅니다.

**3번은 처음 한 번만 하시면 됩니다.** 그다음부터는 평소처럼 더블클릭으로 열립니다.

그냥 더블클릭부터 하시면 "손상되었기 때문에 열 수 없습니다"라는 경고가 나올 수 있습니다.
겁나는 문구지만 파일이 손상된 게 아닙니다. 애플 개발자 인증서(연 99달러)를 사지 않은
프로그램에 macOS가 붙이는 기본 경고이고, 위의 우클릭 방법으로 한 번만 열어주시면 사라집니다.

그래도 열리지 않으면 터미널을 켜고 아래 한 줄을 붙여넣은 뒤 엔터를 치세요.

```
xattr -dr com.apple.quarantine /Applications/hanji.app
```

### 브라우저에서 쓰기

같은 기능을 설치 없이 웹에서도 쓸 수 있게 만들어 뒀습니다.
다만 아직 주소를 열지 않았습니다. 준비되면 이 문단과 [README](../README.md)에 주소를 적겠습니다.

## 2. 문서 열기

창 아무 데나 파일을 끌어다 놓으세요. 그게 전부입니다.

작은 칸에 정확히 맞출 필요는 없습니다. 창 전체가 받는 자리로 되어 있습니다.
끌어다 놓기가 번거로우면 오른쪽 위 **파일 열기** 버튼을 눌러 고르셔도 됩니다.

열 수 있는 파일은 이렇습니다.

| 종류 | 확장자 |
|---|---|
| 한글 | `.hwp` `.hwpx` `.hml` |
| PDF | `.pdf` |
| 이미지 | `.png` `.jpg` `.webp` `.gif` `.bmp` `.svg` `.avif` |
| 동영상 | `.mp4` `.mov` `.webm` `.m4v` |

## 3. 다른 형식으로 저장하기

문서가 열리면 위쪽에 **다른 형식으로 저장**이라는 줄이 생깁니다.
원하는 형식의 버튼을 누르면 어디에 저장할지 물어보고, 위치를 고르면 끝납니다.

| 지금 연 파일 | 저장할 수 있는 형식 |
|---|---|
| 한글(HWP) | **HWPX**, HML, PDF, PNG |
| 한글(HWPX) | HWP, HML, PDF, PNG |
| PDF | PNG, JPEG |
| 이미지 | PNG, JPEG, WebP |

HWP를 HWPX로 바꾸는 기능 때문에 이 프로그램을 만들었습니다.
2026년 5월 18일부터 공공기관은 개방형 문서 형식을 쓰게 되어 있고, 한글 쪽에서 그 개방형
형식이 HWPX입니다. 화면에 그린 것을 다시 찍어내는 방식이 아니라 진짜 HWPX 문서로 내보냅니다.

알아두시면 좋은 것 두 가지가 있습니다.

쪽이 여러 장인 문서를 이미지(PNG·JPEG)로 저장하면 쪽마다 그림 한 장이 나오기 때문에
`.zip` 파일 하나로 묶어서 드립니다. 압축을 풀면 쪽 번호가 붙은 그림들이 들어 있습니다.

PDF로 저장하면 각 쪽이 그림이 됩니다. 그래서 글자를 마우스로 긁거나 검색하지 못합니다.
버튼 아래에 미리 적어두었으니 누르기 전에 확인하실 수 있습니다.

## 4. PDF 손보기

PDF를 열면 저장 버튼 옆에 편집 버튼도 같이 나옵니다.

| 버튼 | 하는 일 |
|---|---|
| 낱장으로 나누기 | 쪽마다 PDF 한 개씩 만들어 `.zip`으로 묶어 줍니다 |
| 90° 돌리기 | 모든 쪽을 시계 방향으로 한 번 돌립니다. 누를 때마다 더 돌아갑니다 |
| 고른 쪽만 저장 | 옆 칸에 `1-3,7`처럼 적으면 그 쪽만 남긴 PDF를 만듭니다 |

세 가지 모두 문서를 다시 그리지 않습니다. 그래서 **글자를 마우스로 긁거나 검색하는 기능이
그대로 살아 있습니다.** 아래쪽 PNG·JPEG 저장은 쪽을 그림으로 바꾸기 때문에 그 기능이 사라집니다.
같은 줄에 있어도 성격이 다르니 헷갈리지 마세요.

쪽 번호 칸에는 `1-3,7`처럼 적습니다. 하이픈으로 범위를, 쉼표로 여러 개를 잇습니다.
없는 쪽이나 거꾸로 된 범위를 적으면 무엇이 잘못됐는지 알려줍니다.

## 5. 파일 여러 개를 한 번에

**파일을 여러 개 한꺼번에 끌어다 놓아도 됩니다.** 이때는 문서를 보는 화면이 아니라
"이것들로 하나 만들기" 화면이 나옵니다.

| 놓은 것 | 만들 수 있는 것 |
|---|---|
| PDF 여러 개 | 하나로 합치기, `.zip`으로 묶기 |
| 이미지 여러 장 | GIF, PDF |

순서는 **파일 이름 순서**입니다. 끌어다 놓은 순서가 아닙니다.
여러 개를 한 번에 끌면 컴퓨터가 정한 순서로 넘어오는데, 그 순서는 화면에 보이지도 않고
컴퓨터마다 다릅니다. 원하는 순서가 있으면 파일 이름 앞에 `01_`, `02_`처럼 번호를 붙여주세요.

이미지를 놓으면 작은 그림이 순서대로 나열됩니다. 만들기 전에 순서를 확인하실 수 있습니다.

PDF와 이미지를 섞어서 놓으면 만들 수 있는 게 없습니다. 그럴 때는 같은 종류끼리 놓아달라고
알려줍니다.

## 6. 동영상에서 사진 뽑기

동영상 파일(MP4, MOV, WebM)을 놓으면 재생 화면이 나오고, 아래 세 가지를 할 수 있습니다.

| 버튼 | 하는 일 |
|---|---|
| 이 장면 저장 | **지금 보고 있는 화면**을 원본 해상도 PNG로 저장합니다 |
| 장면 여러 장 | 영상 전체에서 고르게 최대 60장을 뽑아 `.zip`으로 묶어 줍니다 |
| GIF로 만들기 | 지금 재생 위치부터 약 5초를 GIF로 만듭니다. 소리는 빠집니다 |

**"이 장면 저장"과 "GIF로 만들기"는 재생 위치를 기준으로 합니다.** 원하는 장면까지 밀어서
맞춘 다음에 누르세요.

동영상은 컴퓨터에 이미 들어 있는 재생 기능으로 엽니다. 그래서 평소에 재생되던 영상은 열리고,
안 되던 영상은 여기서도 안 열립니다. 그런 경우에는 "재생할 수 없습니다"라고 알려드립니다.

자르기나 화질 변경 같은 편집은 없습니다. 그건 영상 편집 프로그램이 할 일입니다.

## 7. 화면 색과 언어

오른쪽 위에 작은 버튼 두 개가 있습니다.

첫 번째는 화면 색입니다. 누를 때마다 시스템(◐), 밝게(☀), 어둡게(☾) 순서로 바뀝니다.
기본값인 시스템은 컴퓨터 설정을 그대로 따라갑니다. 낮에는 밝게, 밤에는 어둡게 쓰시려면
컴퓨터 설정을 그대로 두시면 되고, 항상 어둡게 쓰고 싶으면 어둡게로 고정해 두세요.

두 번째는 **English** 버튼입니다. 눌러서 영어로 바꿀 수 있고, 다시 누르면 한국어로 돌아옵니다.
문서를 열어둔 채로 바꾸셔도 문서는 그대로 있습니다.

## 8. 정말 안 나가는지 확인하는 법

말로 하는 약속이 아니라 직접 확인하실 수 있게 만들었습니다.
방법이 세 가지이고, 뒤로 갈수록 확실합니다.

**화면의 숫자를 보세요.** 오른쪽 위에 "전송 0"이라고 떠 있습니다. 그냥 적어둔 문구가 아니라,
프로그램이 밖으로 보낸 요청을 실시간으로 세고 있는 숫자입니다. 문서를 열고 변환해도 0에서
움직이지 않습니다. 하나라도 나가면 숫자가 올라가고 색이 바뀝니다.

**인터넷을 끊고 써보세요.** 와이파이를 끄거나 랜선을 뽑은 채로 문서를 열어보시면 됩니다.
그대로 동작합니다. 파일을 어딘가로 보내는 프로그램이라면 여기서 멈춰야 정상입니다.
확인에 10초면 충분하고, 이게 두 번째로 확실한 방법입니다.

**코드를 직접 보세요.** 전체 코드를 공개해 두었습니다. 프로그램 본체에는 네트워크 기능이
아예 들어 있지 않습니다. [`src-tauri/Cargo.toml`](../src-tauri/Cargo.toml) 파일을 열어보시면
인터넷에 연결하는 라이브러리가 한 줄도 없다는 걸 보실 수 있습니다.

## 9. 잘 안 될 때

| 이런 증상이면 | 이렇게 해보세요 |
|---|---|
| 맥에서 "손상되었기 때문에 열 수 없습니다" | 우클릭한 뒤 열기를 고릅니다 (1번 항목 참고) |
| 동영상이 "재생할 수 없습니다" | 컴퓨터에 그 코덱이 없습니다. MP4(H.264)나 WebM으로 바꿔서 열어보세요 |
| 여러 개를 놓았는데 순서가 뒤죽박죽 | 파일 이름 순서로 처리합니다. 이름 앞에 `01_`처럼 번호를 붙이세요 |
| GIF 파일이 너무 큼 | 장면 수와 크기에 비례합니다. 더 짧은 구간에서 다시 만들어보세요 |
| 윈도우에서 "PC를 보호했습니다" | 추가 정보를 누른 뒤 실행을 고릅니다 |
| 한글 파일이 안 열림 | `.hwp` `.hwpx` `.hml`만 됩니다. 암호가 걸린 문서는 아직 못 엽니다 |
| 글자가 네모(□)로 보임 | 문서가 쓰는 글꼴이 컴퓨터에 없어서 그렇습니다. 내용은 멀쩡합니다 |
| 표가 옆으로 밀려 보임 | 예전에 있던 문제이고 고쳤습니다. 최신 버전을 받아주세요 |
| 큰 문서에서 느림 | 쪽 수에 비례해서 오래 걸립니다. 100쪽이 넘으면 조금 기다리셔야 합니다 |

이 표에 없는 문제라면 [이곳](https://github.com/sylvanus4/hanji/issues)에 남겨주세요.
GitHub 계정으로 글을 남기는 게시판이고, 개발자가 직접 읽습니다.

한 가지만 부탁드립니다. **파일은 첨부하지 마세요.** 어떤 종류의 문서였는지, 화면에 무엇이
나왔는지만 적어주시면 충분합니다. 파일을 받지 않는 것이 이 프로그램의 취지이기도 합니다.
