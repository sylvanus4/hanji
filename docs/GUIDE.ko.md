# hanji 사용법

한글(HWP·HWPX), PDF, 이미지 파일을 **내 컴퓨터 안에서만** 열고 변환하는 프로그램입니다.
파일을 어디에도 올리지 않습니다.

---

## 1. 설치

### 윈도우

1. [Releases](https://github.com/sylvanus4/hanji/releases)에서 `hanji_x.x.x_x64-setup.exe`를 받습니다.
2. 실행하고 안내대로 누릅니다.
3. 시작 메뉴에서 **hanji**를 실행합니다.

> 설치 중 "Windows에서 PC를 보호했습니다"가 뜨면 **추가 정보 → 실행**을 누르세요.
> 프로그램에 서명(유료 인증서)을 붙이지 않아서 나오는 안내이고, 문제가 있다는 뜻이 아닙니다.

### 맥

1. [Releases](https://github.com/sylvanus4/hanji/releases)에서 `hanji_x.x.x_universal.dmg`를 받습니다.
   (인텔 맥·애플 실리콘 맥 모두 같은 파일입니다.)
2. 열어서 **hanji**를 **Applications** 폴더로 끌어다 놓습니다.
3. **처음 한 번만** — 응용 프로그램 폴더에서 hanji를 **우클릭 → 열기 → 열기**.

> ⚠️ **그냥 더블클릭하면 "손상되었으므로 열 수 없습니다"라고 나올 수 있습니다.**
> 파일이 진짜 손상된 게 아닙니다. 애플 개발자 인증서(연 $99)를 붙이지 않아서
> macOS가 보내는 기본 경고이고, **우클릭 → 열기**로 한 번만 열면 그다음부터는
> 더블클릭으로 그냥 열립니다.
>
> 그래도 안 열리면 터미널에 아래 한 줄을 붙여넣으세요.
>
> ```
> xattr -dr com.apple.quarantine /Applications/hanji.app
> ```

### 설치가 귀찮으면

브라우저에서 바로 쓸 수도 있습니다. 기능은 같습니다.
(주소는 README 위쪽 링크를 참고하세요.)

## 2. 쓰는 법

### 문서 열기

**창 아무 데나 파일을 끌어다 놓으면 됩니다.** 그게 전부입니다.

작은 네모 칸에 정확히 맞출 필요 없습니다. 창 전체가 받는 자리입니다.
끌어다 놓기가 불편하면 오른쪽 위 **파일 열기** 버튼을 눌러 골라도 됩니다.

열 수 있는 파일:

| 종류 | 확장자 |
|---|---|
| 한글 | `.hwp` `.hwpx` `.hml` |
| PDF | `.pdf` |
| 이미지 | `.png` `.jpg` `.webp` `.gif` `.bmp` `.svg` `.avif` |

### 다른 형식으로 저장하기

문서가 열리면 위쪽에 **다른 형식으로 저장** 줄이 생깁니다. 원하는 버튼을 누르면
저장 위치를 묻고, 고르면 끝입니다.

| 지금 연 파일 | 저장할 수 있는 형식 |
|---|---|
| 한글(HWP) | **HWPX**, HML, PDF, PNG |
| 한글(HWPX) | HWP, HML, PDF, PNG |
| PDF | PNG, JPEG |
| 이미지 | PNG, JPEG, WebP |

**HWP → HWPX가 이 프로그램을 만든 이유입니다.** 2026년 5월 18일부터 공공기관은
개방형 문서 형식을 쓰게 되어 있고, 한글 쪽 개방형 형식이 HWPX입니다. 다시 그려서
만드는 게 아니라 진짜 HWPX 문서로 내보냅니다.

> 쪽이 여러 장인 이미지 저장(PNG·JPEG)은 `.zip` 한 개로 묶여 나옵니다.
> PDF로 저장하면 각 쪽이 **그림**이 됩니다. 글자를 긁거나 검색할 수 없습니다.
> 버튼에 미리 적어뒀습니다.

### 화면 색과 언어

오른쪽 위 두 개의 작은 버튼입니다.

- **◐ 시스템 / ☀ 밝게 / ☾ 어둡게** — 누를 때마다 바뀝니다.
  기본값 "시스템"은 컴퓨터 설정을 따라갑니다.
- **English** — 영어로 바꿉니다. 다시 누르면 한국어로 돌아옵니다.

## 3. 정말 안 나가는지 확인하는 법

말로만 하는 약속이 아니라 직접 확인하실 수 있습니다. 세 가지 방법이 있고,
**아래로 갈수록 확실합니다.**

**하나 — 화면의 숫자.**
오른쪽 위에 **전송 0**이라고 떠 있습니다. 장식이 아니라, 프로그램이 실제로 밖에
보낸 요청을 세고 있는 숫자입니다. 파일을 열고 변환해도 0에서 움직이지 않습니다.
하나라도 나가면 즉시 숫자가 올라가고 색이 바뀝니다.

**둘 — 인터넷을 끊고 써보기.**
와이파이를 끄거나 랜선을 뽑고 문서를 열어보세요. 그대로 동작합니다.
파일을 보내는 프로그램이라면 여기서 멈춰야 합니다.

**셋 — 코드 확인.**
전체 코드가 공개되어 있습니다. 프로그램 본체(Rust)에는 네트워크 기능이
아예 들어 있지 않습니다 — [`src-tauri/Cargo.toml`](../src-tauri/Cargo.toml)에
HTTP 라이브러리가 한 줄도 없습니다.

## 4. 안 될 때

| 증상 | 이렇게 해보세요 |
|---|---|
| 맥에서 "손상되었으므로 열 수 없습니다" | 우클릭 → 열기 (위 설치 항목 참고) |
| 윈도우에서 "PC를 보호했습니다" | 추가 정보 → 실행 |
| 한글 파일이 안 열림 | `.hwp` `.hwpx` `.hml`만 됩니다. 암호가 걸린 문서는 아직 안 됩니다 |
| 글자가 네모(□)로 보임 | 문서가 쓰는 글꼴이 컴퓨터에 없는 경우입니다. 내용은 정상입니다 |
| 표가 밀려 보임 | 알려진 문제였고 고쳤습니다. 최신 버전을 받아주세요 |
| 큰 문서에서 느림 | 쪽 수에 비례합니다. 100쪽 넘는 문서는 시간이 걸립니다 |

그래도 안 되면 [이슈로 알려주세요](https://github.com/sylvanus4/hanji/issues).
**파일은 첨부하지 마세요** — 어떤 문서인지, 무슨 화면이 나왔는지만 적어주시면 됩니다.
